# PearlSmile

Dental clinic site with services and appointment booking.

**[Live Demo](https://shaisolaris.github.io/pearlsmile-dental/)**

## Features

- Service and treatment sections
- Appointment booking flow
- Team and testimonial sections
- Trust-forward healthcare design

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Tech

Next.js · React · Tailwind CSS
